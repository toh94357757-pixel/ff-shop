ຕັ້ງຄ່າພື້ນຫຼັງເວັບ

ອັບໂຫຼດຮູບພື້ນຫຼັງເພື່ອນຳໃຊ້ທົ່ວທັງເວັບໄຊ (ຈະເປັນຄື fixed background ຢູ່ດ້ານຫຼັງຂອງທຸກອົງປະກອບ). ຖ້າຕ້ອງການໂພສຮູບແບນເນີໂຄສະນາ (ເຊັ່ນ Free Fire) ໃຫ້ໄປທີ່ໜ້າ "ແບນເນີ Hero" ແທນ.

ຍັງບໍ່ມີພື້ນຫຼັງ (ໃຊ້ຄ່າເລີ່ມຕົ້ນ)

ໂລໂກ ແລະ ຊື່ເວັບ

ປ່ຽນໂລໂກ ແລະ ຊື່ຮ້ານທີ່ສະແດງຢູ່ໜ້າເວັບ. ຖ້າບໍ່ອັບໂຫຼດໂລໂກ, ລະບົບຈະໃຊ້ໄອຄອນເລີ່ມຕົ້ນ.

ແບນເນີ Hero (ໜ້າຫຼັກ)

ອັບໂຫຼດຮູບແບນເນີໂຄສະນາ ຮູບນີ້ຈະສະແດງເປັນພື້ນຫຼັງຂອງສ່ວນ Hero ຢູ່ເທິງສຸດຂອງໜ້າຫຼັກ ໂດຍມີເງົາມືດຄຸມ. ແນະນຳຮູບແນວນອນ ຄວາມລະອຽດສູງ.

ຂໍ້ຄວາມແລ່ນໂປຣໂມຊັນ

ແຖບທີ 1

ຂໍ້ຄວາມນີ້ຈະແລ່ນຢູ່ເທິງສຸດຂອງທຸກໜ້າ. ປະຫວ່າງໄວ້ຫວ່າງເພື່ອເຊື່ອງແຖບນີ້.

ແຖບທີ 2 (ຢູ່ເທິງສຸດ, ແຍກຕ່າງຫາກຈາກແຖບທີ 1)

ປະຫວ່າງໄວ້ຫວ່າງເພື່ອເຊື່ອງແຖບນີ້.

ແຈ້ງເຕືອນເຟສບຸກ (CallMeBot)

ເມື່ອລູກຄ້າແຈ້ງເຕີມເງິນ, ລະບົບຈະສົ່ງຂໍ້ຄວາມແຈ້ງເຕືອນເຂົ້າ Facebook Messenger ຂອງທ່ານໂດຍອັດຕະໂນມັດ (ຜ່ານ CallMeBot) ເຖິງແມ່ນວ່າແອດມິນຈະບໍ່ຢູ່ໜ້າເວັບກໍ່ຕາມ.

ວິທີເອົາ API Key: ເປີດ Messenger, ຄົ້ນຫາ ແລະ ແຊັດກັບ Callmebot → ພິມ create apikey → ມັນຈະສົ່ງ API Key ກັບມາ, ຄັດລອກມາໃສ່ຊ່ອງລຸ່ມນີ້.

AI ອ່ານສະລິບ (ຟຣີ, ບໍ່ໃຊ້ບັດ)

ເມື່ອລູກຄ້າອັບໂຫລດສະລິບ, AI (Google Gemini) ຈະລອງອ່ານຈຳນວນເງິນ/ຊື່ຜູ້ໂອນ/ວັນທີ ອອກມາໃຫ້ໂດຍອັດຕະໂນມັດ ເພື່ອໃຫ້ແອດມິນປຽບທຽບໄດ້ໄວຂຶ້ນ.

ອັນນີ້ຊ່ວຍ "ອ່ານ" ໃຫ້ໄວເທົ່ານັ້ນ ບໍ່ແມ່ນການພິສູດວ່າເງິນເຂົ້າແທ້ — ຄົນປອມສະລິບກໍ່ຫຼອກ AI ໄດ້ຄືກັນ, ແອດມິນຕ້ອງເບິ່ງຮູບແລະຕັດສິນໃຈເອງສະເໝີ.

ວິທີເອົາ API Key ຟຣີ: ໄປ aistudio.google.com → ເຂົ້າສູ່ລະບົບດ້ວຍ Gmail → "Get API Key" → "Create API Key" → ຄັດລອກມາໃສ່ຊ່ອງລຸ່ມນີ້ (ບໍ່ຕ້ອງໃສ່ບັດ, ໃຊ້ຟຣີໄດ້ຕະຫຼອດ ພາຍໃນຂອບເຂດຈຳກັດຕໍ່ມື້).

AI ຈະປະຕິເສດອັດຕະໂນມັດຖ້າຊື່ຜູ້ຮັບເງິນໃນສະລິບບໍ່ກົງກັບຊື່ໃດໜຶ່ງໃນນີ້. ປະຫວ່າງໄວ້ ຖ້າຍັງບໍ່ຢາກເປີດການກວດຊື່ຜູ້ຮັບ.

ອະນຸມັດ/ປະຕິເສດອັດຕະໂນມັດ: ເມື່ອຕັ້ງ API Key ໄວ້, AI ຈະ ອະນຸມັດ ຫຼື ປະຕິເສດການເຕີມເງິນທັນທີ ໂດຍກວດ 4 ຢ່າງ: ຈຳນວນເງິນຕ້ອງກົງກັບທີ່ລູກຄ້າເລືອກ, ຊື່ຜູ້ຮັບເງິນຕ້ອງກົງ (ຖ້າຕັ້ງໄວ້), ບໍ່ມີຮ່ອງຮອຍການແກ້ໄຂຮູບ, ແລະ ເວລາໂອນໃນສະລິບຕ້ອງບໍ່ເກີນ 20 ນາທີ. AI ຍັງອາດຜິດພາດໄດ້ (ຖືກຫຼອກດ້ວຍສະລິບປອມ ຫຼື ປະຕິເສດລູກຄ້າແທ້ຜິດຄົນ) — ເບິ່ງ "ການຕັດສິນຂອງ AI ຫຼ້າສຸດ" ໃນໜ້າ "ຢືນຢັນການເຕີມເງິນ" ເພື່ອກວດ ແລະ ແກ້ໄຂຄືນໄດ້ທຸກເວລາ.
